# Multilingual support

Nello uses Lingui message macros and lazy-loaded PO catalogs. English is the source and fallback language; Italian is the first translated language.

## Architecture

- `lingui.config.ts` registers locales and maps catalogs to `src/locales/{locale}/messages.po`.
- `src/i18n.ts` validates supported locale codes, loads one catalog at a time, and persists the preference under `nello.locale`.
- `src/main.tsx` activates the stored locale before rendering and supplies it through `I18nProvider`.
- Components use Lingui's `t` macro. The Vite configuration transforms macros for development, builds, and Vitest.
- The language selector in `src/components/UserSettings.tsx` activates and stores a locale without reloading the page.

## Add a language

For a locale such as French (`fr`):

1. Add `fr` to `locales` in `lingui.config.ts`.
2. Add `fr` to the `locales` tuple in `src/i18n.ts`. This also extends the `Locale` type and allows its catalog to be loaded.
3. Add `<option value="fr">...</option>` to the language selector in `src/components/UserSettings.tsx`. Wrap its visible name in `t` so the language name is translated too.
4. Extract current source messages:

   ```bash
   npm run extract
   ```

   Lingui creates `src/locales/fr/messages.po` and updates every existing catalog.

5. Fill every `msgstr` in `src/locales/fr/messages.po`. Keep ICU placeholders such as `{0}` and `{name}` unchanged. An empty translation falls back to the English source text.
6. Compile all catalogs:

   ```bash
   npm run compile
   ```

7. Verify extraction reports no unexpected missing translations, then run:

   ```bash
   npm run test
   npm run build
   ```

Commit the new PO catalog. Compiled `messages.js` files are generated by `npm run compile` and are also refreshed automatically by `npm run build`.
